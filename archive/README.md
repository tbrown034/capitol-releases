# Archive

Point-in-time investigation artifacts. Nothing in this directory runs in production.

- `scripts/` — one-off Node scripts written to diagnose or repair specific past data incidents. Each ran once, did its job, and is kept as a record of the method.
- `recon/` — site-survey output (probe scripts, JSON results, notes) from planning the Senate, House, and state collector waves.
- `research/` — state-expansion survey artifacts from the 2026-05 recon.

The living pipeline is `pipeline/`; its operational repair scripts are `pipeline/scripts/`.
